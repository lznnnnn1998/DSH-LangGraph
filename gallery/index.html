Under the hood

Prose, law, a clerk.

The model reads a guide for method and a law for rules. The compiler is deterministic: JSON in, StateGraph out. No model translates the IR.

01
State is the ledger.

What must still be true after a seam: files, extracts, outline, decision. Typed fields and reducers decide how many writers may settle them.

02
A node is a role.

One tool call, one judgment, or an open agent brief. Open-ended work stays in prose, not in a constellation of tiny nodes.

03
A gate is a signature.

The run returns interrupted with a thread. The human answer is raw; the graph resumes from the same checkpoint.

04
A map is one role repeated.

Fan out over a list you did not know until runtime; the join settles the ledger. Append follows input order, not completion order.

Don't graph a two-step task. Use the loop for open-ended work; reach for a graph when the work has a real fan-out you cannot enumerate, a human signature, or a pause that must survive a restart. The gallery's research-brief is the honest middle: the ordinary loop still wins on tokens, but the graph makes the seam explicit and resumable.

Trust boundary

Data, not code.

The model may compose a graph, but it cannot ship JavaScript. The spec is session-owned; the tools are the ones you already gave the agent.

JSON IR only

No arbitrary model-written JS. The compiler is deterministic; the same spec makes the same graph. A published JSON Schema gives editors that same vocabulary.

Session-owned

Specs are immutable and owned by the session that composed them; another session cannot run or delete them.

Tool visibility

A node must name a tool visible to the calling agent; args are checked against the tool's own schema at compose time.

Human gates

Irreversible steps pause with a thread. The answer is raw; the resume is explicit, never a hidden side effect.
